# BunRelay Wiki Home

BunRelay is an open source realtime chat template built for learning, portfolio use, and as a serious starting point for new chat-backed products.

## What it emphasizes

- Bun-native HTTP and WebSocket handling
- Shared protocol validation with Zod
- Simple local setup with SQLite
- Realistic upgrade path to Postgres and Redis
- Practical auth, room governance, and observability defaults

## Project positioning

BunRelay is intentionally a template, not a finished chat product. The backend aims to be credible and reusable, while the frontend remains a lightweight demo for verification and onboarding.
